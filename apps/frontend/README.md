# SPA Contact Frontend

React SPA for displaying, filtering, adding, editing, deleting, sorting, and paginating contacts.

## Run

```bash
npm install
npm run dev
```

The app expects the backend at `http://localhost:8080` by default. Override it with:

```bash
VITE_BACKEND_URL=http://localhost:8080 npm run dev
```

## Scripts

```bash
npm run build
npm run test
npm run check
```
